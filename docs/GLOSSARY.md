# Glossaire français / anglais

| Français | English | Définition |
|---|---|---|
| Attaque par déni de service distribué | Distributed Denial of Service (DDoS) | Trafic coordonné visant à rendre une ressource indisponible |
| Flux réseau | Network flow | Résumé statistique d'une communication réseau |
| Caractéristique | Feature | Variable numérique utilisée par le modèle |
| Étiquette | Label | Classe vraie associée à un exemple |
| Source | Source domain | Dataset utilisé pour le pré-entraînement |
| Cible | Target domain | Dataset utilisé pour l'adaptation ou le modèle final |
| Transfert d'apprentissage | Transfer Learning | Réutilisation de paramètres appris sur une autre tâche/domaine |
| Entraînement depuis zéro | Scratch | Initialisation aléatoire sans backbone pré-entraîné |
| Backbone | Backbone | Partie cachée réutilisable du réseau |
| Tête | Head | Couche de sortie adaptée aux classes de la cible |
| Gel | Freezing | Désactivation de la mise à jour de certains paramètres |
| Fine-tuning | Fine-tuning | Réentraînement contrôlé de paramètres pré-entraînés |
| Dégel progressif | Progressive unfreezing | Ouverture graduelle des blocs du backbone |
| Préprocessing | Preprocessing | Conversion, imputation, standardisation et clipping |
| Imputation | Imputation | Remplacement de valeurs manquantes par une statistique apprise |
| Standardisation | Standardization | Centrage-réduction par moyenne et échelle du train |
| Fuite de données | Data leakage | Information de validation/test utilisée indûment |
| Décalage de domaine | Domain shift | Différence de distribution entre source et cible |
| Fraction faible | Low-data regime | Entraînement avec une petite partie des annotations |
| Macro F1 | Macro F1 | Moyenne non pondérée des F1 de classes |
| Weighted F1 | Weighted F1 | F1 pondéré par le support des classes |
| Support | Support | Nombre d'exemples vrais d'une classe |
| Matrice de confusion | Confusion matrix | Comptage des classes vraies et prédites |
| Seed | Random seed | Graine contrôlant les générateurs aléatoires |
| Intervalle de confiance | Confidence interval | Plage d'incertitude autour d'une estimation |
| DataLoader | DataLoader | Itérateur de mini-lots d'entraînement |
| Checkpoint | Checkpoint | Fichier contenant les poids sauvegardés |
| Inférence | Inference | Production de prédictions sans mise à jour des poids |
| Confidence | Confidence | Probabilité maximale affichée pour une prédiction |
