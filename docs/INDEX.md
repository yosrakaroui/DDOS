## Parcours recommandé

- Pour comprendre le projet : `PROJECT_OVERVIEW.md`, puis
  `PROJECT_TIMELINE.md`.
- Pour reproduire le pipeline : `COMMANDS_GUIDE.md` et
  `SCIENTIFIC_METHODOLOGY.md`.
- Pour analyser les résultats : `EXPERIMENTAL_RESULTS.md`.
- Pour préparer une démonstration : `STREAMLIT_APPLICATION.md` et
  `PROJECT_STATUS.md`.

## Traçabilité

Les résultats numériques sont ceux des rapports et fichiers du repository.
Les éléments non confirmés, notamment un test navigateur complet et un test
réel CSV persisté, sont explicitement signalés comme restant à vérifier.
